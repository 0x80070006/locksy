# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir de ticket public. Utilisez le signalement privé de GitHub :
onglet **Security** du dépôt > **Report a vulnerability**.

Indiquez la version concernée, les étapes pour reproduire et l'impact estimé. Nous accusons
réception sous 7 jours et publions un correctif dès que possible, avec mention du découvreur
s'il le souhaite.

## Versions maintenues

Seule la dernière version publiée reçoit des correctifs de sécurité.

## Périmètre

Le modèle de sécurité et ses limites connues sont décrits dans [SECURITE.md](SECURITE.md) et
[docs/Chiffrement-et-securite.md](docs/Chiffrement-et-securite.md). Les limites qui y sont documentées (par exemple, un
serveur compromis peut servir une interface web modifiée) ne sont pas des vulnérabilités en
soi, mais toute idée pour les réduire est bienvenue.
